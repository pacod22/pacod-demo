GW

pacod-gw

AI gateway

A first-class, high-performance gateway between your applications and every LLM provider, built for performance, scalability, flexibility, advanced monitoring and ease of use.

A Rust core relays or translates every call, keeps provider keys out of the apps, enforces quotas and prices each request. A SvelteKit console manages all of it. In the demo, every product's model calls go through it. With no provider key set, its mock provider answers.

  • Rust
  • Tokio & hyper
  • PostgreSQL
  • ClickHouse
  • Valkey
  • SvelteKit

console.{{$d}}{{$p}}
  • PerformanceRust on Tokio and hyper. Responses stream straight through, configuration is an in-memory snapshot read with one atomic load, and keys are checked without touching a database. Proxy mode relays content untouched. A call at temperature 0 that repeats is answered from a response cache in Valkey, shared by every instance, without asking the provider.
  • ScalabilitySeveral instances share one database, and a change reaches all of them within about a second. Limits are counted in memory and usage events are spooled to disk before they reach ClickHouse. It runs as one container without a database (lite), or at scale with a Helm chart.
  • FlexibilityOpenAI (chat and Responses), Anthropic (in full) and Gemini dialects, translated in every direction. Beyond chat: embeddings, speech, images, transcription, rerank, Realtime sessions, and files and batches. Providers include OpenAI, Anthropic, Gemini and Vertex AI, DeepSeek, GLM, Kimi, Groq, Cohere, Jina, Voyage and Ollama. Proxy mode forwards content byte for byte, WebSockets included, and managed mode adds templates.
  • Smart routingModel pools with priority, weighted, round-robin, least-busy, lowest-latency or cheapest routing. Calls fail over before the first byte, circuit breakers isolate failing models, and session affinity keeps prompt caches warm.
  • Advanced monitoringThe delay the gateway adds is measured and stored for every call. Usage, tokens and cost go to ClickHouse, with Prometheus metrics, Grafana dashboards and alerts, and an audit mode that keeps complete requests and responses.
  • UsabilityOne console for models, templates, keys, versioned prices, quotas and reports, down to what the response cache saved. Changes take effect live, without a restart. A built-in tester runs test cases and load tests against the gateway.
CM

pacod-cms

Content management

A modern, highly flexible and user-friendly CMS, with AI-assisted tools throughout: content generation, translation and PDF creation.

Articles, authors and categories, standing pages, an image library, advertising and statistics for editorial websites. One installation hosts many websites, each with its own database, files and cache.

The demo has three websites, one per template set: Demo Journal (editorial), Demo Notes (minimal) and Starward (magazine). Starward is an image-led space-travel magazine for an invented star system, with NASA photographs and animated HTML5 advertising.

AP

pacod-ap

Agent builder

An easy-to-use platform for building AI agents, with full control over the AI: what each agent knows, which models and tools it uses, what it may say, and how it improves.

Any number of self-contained AI agents on one deployment. Each has its own knowledge base, reference facts, prompts, directives, conversations and reviews, behind one sign-in and one admin console.

The demo runs the starter agent, a small fictional help desk.

  • Visual agent editorBuild an agent as a pipeline of components and set each step in a form, with no code. Existing agents can be brought into the editor without changing how they behave.
  • AI that helps you buildThe editor's assistant drafts prompts, scope descriptions and guard messages from your instructions. Each suggestion is validated like a saved draft, and you decide what to apply.
  • Full AI controlFor each agent you choose the models, the allowed tools, the planner, the topic guard and the languages. Directives take precedence even over what the tools return.
  • Safe releasesVersions never change once saved. Test a draft against its own dev deployment, publish it when it is ready, and roll back in one step.
  • Grounded answersEvery agent has its own knowledge base and curated knowledge, reference facts and MCP tools, and answers from them. Each agent's knowledge, conversations and settings stay its own.
  • Improves continuouslyA review loop finds failed answers in recent conversations and proposes fixes: knowledge, facts and test cases. By default, a person approves them before they reach the live agent. Every model call is costed by the gateway.

BM

pacod-benchmark

Gateway benchmarks

Measures pacod-gw in managed and proxy mode, pacod-gw-lite and other gateways, over a matrix of settings: response cache, audit, streaming, translation and load. Every run gets an organisation of its own, removed afterwards, and a direct call to the mock as its baseline, so the gateway's own overhead shows. Reports are published to the gateway console.

Here its load agent runs on the same machine as the gateway: the figures show how the gateway behaves, not its capacity.
